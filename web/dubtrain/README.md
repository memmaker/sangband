# Dubtrain Angband Sound Pack v3.1.0 (the samples Sangband's web build uses)

Sounds by Dubtrain <angband@dubtrain.com> (http://www.dubtrain.com/angband/),
licensed under the Creative Commons Attribution 4.0 licence.

These MP3 files and `sound.prf` are copied unchanged from Angband's
`lib/sounds/` and `lib/customize/sound.prf` (github.com/angband/angband,
commit 1d2ad35a2fc8), where the pack ships as Angband 4.2's default sound set
(via the NPPAngband web port's copy, memmaker/nppangband `web/dubtrain`).
Only the files that fill events Sangband's own samples (`lib/xtra/sound`)
leave empty are kept, plus `plc_miss_swish` for a melee miss.
`web/sounds.py` writes the web build's `sound.cfg`.
